## React TypeScript

### About

This repository contains react-typescript projects exploring how Typescript integrates with React, from basic component props and event handling to generics, advanced props, and context-based patterns.

It also includes a separate [`react-hook-typescript`](react-hook-typescript) project for exploring React Hooks with TypeScript.

### Topics Covered

- **React Components with TypeScript** — creating and typing functional components
- **Props and Prop Types** — passing typed data between components
- **Reusable Components** — building components such as buttons, containers, headings, and inputs
- **Children Props** — working with component children
- **Generics** — creating reusable generic components and lists
- **Advanced Props** — exploring advanced component prop patterns
- **Polymorphic Components** — working with components that support different element types
- **Utility Types and Prop Extraction** — deriving props from existing components
- **Event Handling** — handling React events with TypeScript
- **State and Class Components** — practicing state-related component patterns
- **React Hooks with TypeScript** — practicing state, refs, and context


### Getting Started

Run either project independently from its directory.

```bash
cd react-typescript
npm install
npm start
```

For the Hooks project:

```bash
cd react-hook-typescript
npm install
npm start
```

The available scripts may differ, so check each folder's `package.json` if `npm start` is not configured.

### Purpose

This repository serves as a practical reference for learning TypeScript's type system through React development, with an emphasis on reusable components, props, generics, and Hooks.
